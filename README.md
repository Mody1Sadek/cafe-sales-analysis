# Cafe Sales Analysis & Interactive Dashboard

## Project Overview

This project focuses on analyzing cafe sales data to understand sales performance, customer purchasing patterns, and revenue trends.

Python was used for data analysis, exploration, and visualization, while Power BI was used to create an interactive dashboard for presenting key findings and KPIs.

## Objectives

* Analyze overall cafe sales performance
* Identify revenue and sales trends
* Understand product performance
* Analyze sales across different periods
* Identify patterns in customer purchasing behavior
* Build an interactive dashboard to communicate insights clearly

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* Power BI

## Project Workflow

### 1. Data Preparation

The cafe sales dataset was prepared and structured for analysis, ensuring that the required fields were in a suitable format for further analysis.

### 2. Exploratory Data Analysis

Python was used to explore the dataset and analyze:

* Sales performance
* Revenue trends
* Product performance
* Quantity sold
* Time-based sales patterns
* Relationships between different variables

### 3. Data Visualization

Different visualizations were created using Python to identify trends and patterns and make the analysis easier to understand.

### 4. Power BI Dashboard

The analyzed data was used to build an interactive Power BI dashboard that provides an overview of cafe sales performance and allows users to explore the data through interactive visuals and KPIs.

## Key Analysis

The project includes analysis of:

* Total Revenue
* Total Quantity Sold
* Sales Trends
* Product Performance
* Average Order Value
* Average Unit Price
* Sales by Time Period

## Dashboard

The Power BI dashboard provides an interactive view of the cafe's sales performance and helps transform raw sales data into clear and actionable insights.
